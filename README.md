# TTB Copilot Studio 2026

เว็บไซต์แบบฝึกหัดสำหรับ TTB AI Agent Day สร้างด้วย VitePress และเผยแพร่ผ่าน GitHub Pages

## Local development

```bash
npm install
npm run docs:dev
```

## Production build

```bash
npm ci
npm run docs:build
npm run docs:preview
```

เนื้อหาสำหรับผู้เรียนเป็นข้อมูลจำลองสำหรับการฝึกอบรม ห้ามใช้ข้อมูลลูกค้า ข้อมูลส่วนบุคคล หรือข้อมูลภายในจริงในการฝึก
